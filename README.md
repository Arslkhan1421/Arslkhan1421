## Featured project

### [Beyond SEO](https://github.com/Arslkhan1421/beyond-seo-skill)

An SEO and AEO/GEO skill for AI agents, supported by deterministic Python tools and clear, actionable PDF reports.

- Technical crawl analysis and offline host-agent data ingestion
- Source-labelled findings with explicit coverage and measurement limits
- GSC, GA4 and Microsoft Clarity export analysis
- Structured-data, international SEO and internal-link review workflows
- Client-ready reports with prioritized actions and validation steps
